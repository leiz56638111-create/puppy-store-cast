# 小狗便利店投屏 1.0.2

2026-11-11完成功能构建，2026-11-23发布至GitHub。正式安装包，包名cn.local.livingroomcast，versionCode12，沿用原签名，可直接覆盖1.0.1及旧主版。独立镜像测试包仍是另一应用，安装正式版不会替它卸载。测试时先退出其他接收器。

## 更新内容

- 修复AirPlay镜像显示区域变化后，GL绘制仍使用旧尺寸导致的放大和裁切。窗口变更后同步重新绑定，每次绘制读取实际宽高；静止画面也可重新绘制。
- AirPlay镜像控制条增加“画面大小”：100%默认、90%、80%、70%、60%、50%，保持比例居中并保存。地址视频直投和DLNA不套用这个镜像设置。
- 连接详情新增实际监听端口、累计连接数、广播注册结果、固定协议阶段；身份初始化失败时中止启动，避免继续公布不可用接收器。阶段处理函数返回不代表已成功验证身份。
- 保留测试版中提交新压缩帧前提取已就绪解码输出的调整；没有证据证明已消除1～2秒延迟，不作为低延迟保证。

## 使用

将APK拷入U盘安装，打开“小狗便利店投屏”。安卓视频App点TV/投屏选择同名设备；iPhone/iPad先切换电视端AirPlay，再使用控制中心“屏幕镜像”或支持的App内“隔空播放”。

镜像中按遥控器确认键呼出控制条，选择“画面大小”，用上下键选档并确认；触摸设备可点击操作。选“完整显示（默认）”恢复。

两模式仍互斥，后台待机和自动打开的系统权限要求延续1.0.1；播放中按Home结束本次播放并继续待机。不含开机自启或在线更新。

## 本轮用户复测

用户确认独立test2在其iPad上显示比例正常；iPhone27.2开启Shadowrocket时正式版与测试版均失败，关闭VPN后可投。iPad为27.0。此结论不扩写为所有VPN或所有27.2设备均有故障，也没有证据表明苹果封禁本软件。正式版仍需在用户设备确认覆盖升级后的表现。

连接失败时，可先临时断开VPN做对照；若仍失败，在电视连接详情中查看累计连接数和协议阶段。不要仅凭设备列表出现名称就认定连接已建立。记录只留在本次运行内存，不记录完整视频地址、授权报文或配对密钥。

## 兼容边界

DLNA最低Android6/API23，AirPlay需要Android7/API24以上ARM设备，含ARM64/ARM32。片源提供哪些画质仍由发送端与接收设备能力决定，不新增Chromecast、Miracast、DRM绕过或4K60/HDR保证。游戏延迟、长时间声画同步、32位运行和API23运行仍待专项验证。
