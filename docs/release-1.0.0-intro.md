小狗便利店投屏 1.0.0 来了 🐶

这次把 DLNA 和 AirPlay 合到了一个 App 里，一个安装包、一个图标。

安卓手机／平板看视频，在视频 App 里点「TV／投屏」，选择「小狗便利店投屏」。
iPhone／iPad 则先在接收端首页点「AirPlay」，再用 App 内的隔空播放，或控制中心的屏幕镜像。

原来的 DLNA 功能也都保留了：触摸和遥控器操作、可拖动进度条、0.5–2 倍速、片源提供的清晰度选择，以及后台待机。

适用于安卓电视和安卓平板。免费、开源、无广告、无订阅，不设人为投屏时长限制。旧主版可以直接覆盖升级。

使用时在 DLNA 和 AirPlay 之间切换，返回即可恢复 DLNA。AirPlay 目前需保持前台；直播回看、进度、倍速和清晰度取决于片源，不同 App 的兼容情况以实测为准。
