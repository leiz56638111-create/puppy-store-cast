# 独立上游对照版 0.4.0-upstream-alpha1

2026-10-27。用户确认先做独立对照版，不合并/发布正式版。基于 `airplay-video-experiment` 的 alpha4，增加 `reference` 独立应用，包名 `cn.local.livingroomcast.airplayreference`、versionCode 1、发现名“小狗便利店投屏·上游对照”。原签名，独立数据与配对身份，和 alpha4、公开版、上游原包可并存；一次只运行一个接收器。

内核来自 jqssun/android-airplay-server v0.0.36 / a46cca0，完整移入接收/JNI、原生音频时间线和 FFmpeg 后备解码、Oboe、解码器选择与持久 GL Surface、NSD、Media3 播放和音量/DACP 调度。16 个关键内核/渲染源文件与固定上游逐字节一致。保留默认自动尺寸/申请60fps/AAC开/ALAC广播关/自动缓冲/预约呈现关；不将申请值写成显示能力或实测帧率。SDK/NDK/AGP沿用本项目36/28.2/8.11.1；Oboe从源码静态构建。上游UI/开机自启/后台/自动拉起/下载功能未导入。

保留中文原生按钮、遥控器绿色焦点与触摸，增加只存本次内存的脱敏诊断；Home/退出停服务。0010/0011 补丁携带适用的请求类型/长度/起点/标识边界、同会话换URL、旧会话控制拒绝与非36字会话断言修复；0001–0009 上游补丁均保留。修复 LifecycleService 缺失 super 调用、首次确认键呼出栏误点击、失败后重试；停服务唤醒等待中的 /play，避免主线程等待至超时。直投播放器在关服前同步释放，旧播放器回调按代次忽略；首帧检查等待 Surface 就绪，避免无数据窗口导致误判。

验证范围：Android12/API31 ARM64 专用模拟器上的9项原生检查，真实 MP4/HLS 解码输出（含音频计数/首帧/Surface像素）、反向HTTP/FCUP列表播放、同会话换视频/旧停止拒绝、异常请求、上游默认值、实际Bonjour回应、H.264回调注入与持久Surface、原生D-pad、音频格式与Oboe设备启动、Home停服/重开；2项URL/起点单元检查，Lint0错误/17警告。实际安装包/精确结果/校验值以交付验收JSON为准。

没有真实苹果设备握手或B站新验收；镜像流测试为合成H.264回调注入，音频原生检查只覆盖配置/Oboe启动，未以真实RTP/ALAC编码包听辨。MP4/HLS音频计数来自Media3，不能拿来证明AirPlay原生音频解码已实测。32位只构建，无实机运行。B站问题与Sony横向花屏保留为待验证，不能写已解决；未测试DRM、4K60、HDR、延迟、长播放同步。

首轮发现的测试问题与修复证据保留在工作区 reference-first/、reference-second/；最终源码APK与测试证据分开保存。测试工具已区分反向 /event 请求与 HTTP 状态响应，避免把测试解析错误写成接收内核故障。

真机请用同一手机/电视/网络/同一视频，依次比较 alpha4、上游原包0.0.36、本对照版：相册独立视频、B站App内AirPlay、B站同视频控制中心镜像、5–10分钟正常播放及断开重连。失败时记录入口、实际版本、声画状态、详情页，不以“菜单可发现”代替播放通过。
